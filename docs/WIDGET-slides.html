這是什麼？

新 Widget

  • 檔案：inf-product-carousel-widget.js
  • 入口：InfFitsProductCarousel.mount()
  • Tag：<inf-product-carousel-widget>
  • ESM：await import(...) 即可
  • 一次可掛 product + popup

與舊版關係

  • 舊檔完全不動、互不依賴
  • 舊：initInfProductCarouselComponent
  • 新舊可同頁並存（不同 tag）
  • 參數結構對齊既有慣例
  • 適合新站／新整合優先採用

兩行用法（核心）

await import('https://…/inf-product-carousel-widget.js');

window.InfFitsProductCarousel.mount({
  brand: 'DES',
  GA4Key: 'G-XXXXXXXXXX',
  carousels: [
    { type: 'popup',  /* ... */ },
    { type: 'product', showPositionId: { top: 'infFitsHeader', bottom: 'infFitsFooter' } }
  ]
});

本機示範：demo-widget.html ｜ 完整文件：WIDGET.md

開始前準備

  • 頁面先放容器，id 要與 showPositionId 一致
  • 常見：#infFitsHeader、#infFitsFooter
  • popup 內容通常掛 popupProductContent
  • 必須提供 carousel 或非空的 carousels，否則 throw
  • 有傳 carousel 時優先單筆，不展開 carousels

回傳：單實例為 Element；多實例為陣列

兩種輪播型態

product（嵌入）

  • 掛在頁面 header / footer
  • 會打品牌設定 API GetItems
  • 可傳 brandConfig 覆寫 API
  • 推薦 endpoint 依品牌／系列分流
  • 適合商品詳情頁搭配推薦

popup（浮動）

  • 左下角 #infPopupproductCarousel
  • 需 brandConfig.status === true
  • autoShow 控制是否自動跳出
  • 專用推薦 endpoint（pidinfo）
  • showPopup / closePopup / resetRecom

參數怎麼記（頂層）

  • brand：品牌代碼（API 用）
  • GA4Key：有才追蹤；空字串＝關閉 GA4
  • carousel：單筆設定
  • carousels：多筆陣列，可同時掛 product + popup
  • 不另發明「自動猜 brand／GA4」；請明確傳入

carousel 常用欄位

  • type / showPositionId / hide_size / hide_discount
  • skuContent：shopline_sku｜app91_sku｜或直接 PID
  • series_in / series_out：系列白／黑名單（JSON 字串）
  • bid：試穿體型參數（影響 SIZEAI）
  • brandConfig：Title、RecommendMode、Location、status、autoShow…
  • recommendMode：bhv,corr,sp_atc,sp_trans
  • customEdm：有值則略過 API，用自訂商品

GA4 事件（有 GA4Key 才發）

  • 商品：{recom_}click_embedded_itemA（如 bhv_ / corr_）
  • 桌面箭頭：click_embedded_item_arrow_leftA / _rightA
  • 手機標題導覽：title_nav_prevA / title_nav_nextA
  • 每次點擊只打 1 筆；category = infEmbeddedAdContainer-embedded
  • 商品點擊另打後端 mkt_click_action_record（與 GA4 並行）
  • 箭頭／標題導覽不會打後端點擊 API

寬螢幕用箭頭；窄螢幕或非 center 用 title-nav

Popup 操作 API

  • window.showPopup()：顯示（autoShow=false 時會先載入）
  • window.closePopup()：關閉
  • window.resetRecom(newBid?)：重拉推薦，可覆寫體型
  • 除錯：popupautoShow / hasValidPopupData / resetRecomCalled
  • 輔助：debugCarousel()、cleanupInfCarouselCache()

最小可用範例（僅 product）

await import('./inf-product-carousel-widget.js');

window.InfFitsProductCarousel.mount({
  brand: 'DES',
  GA4Key: 'G-G3WD6KWQG4',
  carousel: {
    type: 'product',
    showPositionId: {
      top: 'infFitsHeader',
      bottom: 'infFitsFooter'
    }
  }
});

常見問題速查

  • 沒畫面？檢查容器 id、brandConfig.status、popup 是否需手動 showPopup
  • 重複 mount 沒新建？相同 type + showPositionId 會回傳既有實例
  • 關閉追蹤？不傳 GA4Key 或傳空字串
  • 指定商品？skuContent 設為實際 PID／SKU 字串
  • 同頁舊新並存？可以，但勿同時掛兩套 popup
