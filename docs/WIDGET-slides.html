Overview

這是什麼？

新 Widget

  • 檔案：inf-product-carousel-widget.js
  • 入口：InfFitsProductCarousel.mount()
  • Tag：<inf-product-carousel-widget>
  • Shadow DOM 渲染，自行載入 jQuery／Swiper
  • 一次 mount 可同時掛 product + popup

舊 關係

  • 舊檔 inf-product-carousel-component.js 不動
  • 互不 import、互不依賴
  • 新舊可同頁並存（不同 tag）
  • 參數結構對齊既有慣例
  • 新站／新整合建議走 Widget

Quick start

兩行就能掛上

await import('https://ts-inf-product-carousel-component.vercel.app/inf-product-carousel-widget.js');

window.InfFitsProductCarousel.mount({
  brand: 'DES',
  GA4Key: 'G-XXXXXXXXXX',
  carousels: [
    { type: 'popup',  /* brandConfig / bid … */ },
    { type: 'product', showPositionId: { top: 'infFitsHeader', bottom: 'infFitsFooter' } }
  ]
});

本機可用相對路徑：await import('./inf-product-carousel-widget.js') · 示範頁 demo-widget.html

Setup

頁面準備與 mount 規則

容器

  • 先放 DOM，id 與 showPositionId 一致
  • 常見：#infFitsHeader、#infFitsFooter
  • popup 內容多掛 popupProductContent

規則

  • 必須有 carousel 或非空 carousels，否則 throw
  • 有 carousel 時只跑單筆（優先）
  • 同 type + showPositionId 不重複建立
  • 回傳：單 Element 或陣列

Types

product / popup

1 product 嵌入

  • 掛在頁面 header／footer
  • 打品牌設定 API GetItems
  • 可傳 brandConfig 覆寫
  • 推薦 URL 依品牌／系列分流
  • 適合商品詳情頁搭配

2 popup 浮動

  • 左下角 #infPopupproductCarousel
  • 需 brandConfig.status === true
  • autoShow 控制是否自動跳出
  • 專用推薦 endpoint（pidinfo）
  • showPopup / closePopup / resetRecom

Config

參數怎麼記

頂層

  • brand：品牌代碼
  • GA4Key：有才追蹤；空＝關 GA4
  • carousel／carousels：單／多筆
  • 不自動猜 brand／Measurement ID

carousel 常用

  • type、showPositionId
  • skuContent：平台或直接 PID
  • series_in / out、bid
  • recommendMode、customEdm
  • hide_size、arrowPosition

Brand config

brandConfig 與推薦模式

欄位作用
Title / Description標題與描述
DisplayModeSaleRate / SocialProofNum…
RecommendModebhv,corr,sp_atc,sp_trans
CarouselButtontrue→箭頭 center；false→標題導覽
Location / status / autoShow掛載位置、啟用、popup 自動顯示

商品卡會帶 data-event-recom，決定 GA4 事件名前綴（bhv_ / corr_ …）

Analytics

GA4 與後端點擊

GA4（需 GA4Key）

  • 商品：{recom_}click_embedded_itemA
  • 箭頭：…arrow_leftA / _rightA
  • 標題導覽：…title_nav_prevA / _nextA
  • 每次互動只打 1 筆
  • 寬螢幕箭頭；窄螢幕 title-nav

後端紀錄

  • 僅商品點擊 POST mkt_click_action_record
  • 與 GA4 並行、互不取代
  • 箭頭／標題導覽不打此 API
  • 含 recom_type、recom_loc、pid…

Runtime API

Popup 控制與輔助

顯示

  • showPopup()
  • closePopup()
  • resetRecom(bid?)

狀態

  • popupautoShow
  • hasValidPopupData
  • resetRecomCalled

除錯

  • debugCarousel()
  • cleanupInfCarouselCache()

試穿完成後常見流程：resetRecom(newBid) → showPopup()

Recipes

最小範例與常見問題

await import('./inf-product-carousel-widget.js');
window.InfFitsProductCarousel.mount({
  brand: 'DES',
  GA4Key: 'G-G3WD6KWQG4',
  carousel: {
    type: 'product',
    showPositionId: { top: 'infFitsHeader', bottom: 'infFitsFooter' }
  }
});
  • 沒畫面？查容器 id、status、popup 是否要手動 show
  • 關追蹤？不傳或空 GA4Key
  • 指定商品？skuContent 設成 PID 字串
  • 同頁舊新可並存，但勿同時掛兩套 popup
